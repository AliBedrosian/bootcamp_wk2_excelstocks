# 📈 Excel Stock Data Automation (VBA + Excel)
This project demonstrates the use of VBA (Visual Basic for Applications) to process and analyze large datasets across multiple Excel worksheets. The goal was to summarize stock data by quarter and automate repetitive tasks using a reusable VBA module.

🧠 What I Did
Developed a modular VBA script to run consistently across multiple sheets

Replaced hard-coded values with dynamic variables to loop through all rows and handle varying datasets

Created a macro-enabled module that can be reused or applied to new sheets with one click

Used test-driven development to build functionality for a single stock, then scaled the logic to handle full datasets

🔄 Key Features
Automates data parsing, summary calculations, and formatting for each stock

Improves spreadsheet readability with cleaner data organization

Runs efficiently across thousands of rows and multiple worksheets

📁 Deliverables
.vba and .txt versions of the script for accessibility

Screenshots showing macro results on various sheets

Step-by-step documentation in the workbook for future reference

🧰 Tools Used
Excel (multi-sheet)

VBA (modular scripting & macro creation)

Data cleaning, automation, and testing logic
